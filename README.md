# Paper 5 — Bull Put Credit Spread on NIFTY 50

A cost-aware empirical investigation of bull put credit spreads on NIFTY 50.

**Key results:** Sharpe 2.35, Calmar 5.34, max DD −15.0% (with equity-curve stop).

See Paper 6 (`nifty-bull-put-ml-enhanced`) for the ML ablation that extended this work.
